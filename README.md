# Ravula Sahithi — Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS and JavaScript**.

## Live website with GitHub Pages

1. Create a new repository on GitHub, for example `portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. GitHub will provide your Pages URL.

## Before publishing

- Replace `your-email@example.com` in `index.html` with your actual email.
- Add your resume as `assets/resume.pdf`.
- If desired, add a professional photo as `assets/profile.jpg` and update the hero section.
- Add links to individual project repositories when they are available.
- Replace or add certifications with verified certificate links.
